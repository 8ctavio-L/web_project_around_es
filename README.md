# Tripleten web_project_around_es Sprint No.7

Proyecto: Around The U.S.

HTML5: Uso de etiquetas semánticas y atributos de validación nativa (required, minlength, maxlength, type="url", novalidate). Se agrego Span, para validacion de formularios.

CSS3: Maquetación adaptativa (Responsive Design) con Flexbox, Grid Layout, Media Queries y pseudo-clases como :disabled y required.

JavaScript (ES6): Manipulación avanzada del DOM, control de eventos en tiempo real control de accesibilidad en modales. Asi como validacion de formularios a traves de funciones JAVA y evt para detectar el cierre de modales fuera de las ventanas emergentes.
